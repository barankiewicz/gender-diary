# Support policy

Support for this project is intentionally narrow: enough detail to reproduce a
problem, without asking anyone to hand over private journal content.

## Where to ask for help

- General bugs and questions: GitHub Issues.
- Security-sensitive issues: use the private process in `SECURITY.md`.

## What to send

- App version from Settings -> About.
- Platform (web or Android build), browser and OS version.
- Reproduction steps using synthetic entries if possible.
- The exact error message text, redacted if it contains personal content.

## What support will never ask for

- Archive files.
- Screenshots that show entries, notes, reminders, labs or photos.
- Raw logs that include journal content.

Why: those files can contain a complete transition history. Most bugs can be
reproduced from version, platform and steps alone.

## If a private sample is unavoidable

If maintainers cannot reproduce a bug from safe details alone, the next step is
to agree a synthetic reproduction that does not use personal data.
